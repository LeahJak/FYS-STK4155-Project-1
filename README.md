#### Overview
This project studies polynomial regression applied to the one-dimensional
Runge function, f(x) = 1 / (1 + 25x²). We compare linear regression methods,
resampling techniques and gradient-based optimization algorithms.

Topics covered:
- Ordinary Least Squares (OLS), Ridge and Lasso regression
- Bias–variance decomposition
- Bootstrap resampling and k-fold cross-validation
- Gradient descent, including momentum, AdaGrad, RMSProp and Adam
- Stochastic gradient descent
- Automatic differentiation with JAX
